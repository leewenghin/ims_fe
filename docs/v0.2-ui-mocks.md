# Frontend v0.2: UI Mocks

## Goal
Show every module with hardcoded data before the API exists. The screens are the spec the backend builds against.

## Prerequisites
Frontend v0.1 is done. No backend is required.

## Source material
Everything visual comes from the StackAdmin (DashStack) kit in `frontend/ui-material/`:

- `Stack Admin Light Style 1` and `Stack Admin Dark Style 1`: open sidebar with text links.
- `Stack Admin Light Style 2` and `StackAdmin Dark Style 2`: closed sidebar with icons only.
- `Component/`: sidebar items, top bars, labels, buttons, and the light and dark page colors.

The kit is drawn on a 1440 × 1070 frame (the PNGs are 2x). Every pixel value below is a CSS pixel on that frame.

## Theme
Nunito Sans everywhere, one blue (`#4880FF`), light and dark modes.

`globals.css` only sets the shared theme and typography. It does not define component classes. It holds:

- The color and shadow tokens as CSS variables on `:root` (light) and `.dark` (dark), exposed to Tailwind through `@theme inline`.
- `@custom-variant dark` so `dark:` utilities follow the `.dark` class on `<html>`.
- `body`: Nunito Sans, `bg-page`, `text-ink`, 14px.

| Token | Light | Dark | Used for |
|---|---|---|---|
| `page` | `#F5F6FA` | `#1B2431` | Page ground |
| `surface` | `#FFFFFF` | `#273142` | Sidebar, top bar, cards, modals |
| `field` | `#F5F6FA` | `#323D4E` | Inputs, top bar search |
| `head` | `#FCFDFD` | `#323D4E` | Table head row, filter bar, pagination, row actions |
| `panel` | `#F1F4F9` | `#323D4E` | Dashboard table head, login inputs, inset panels |
| `ink` | `#202224` | `#FFFFFF` | Default text |
| `muted` | `#606060` | `#BEC1C6` | Labels, secondary text |
| `faint` | `#A6A6A6` | `#A4A7AD` | Placeholders, chart axes |
| `line` | `#D5D5D5` | `#313D4F` | Borders on cards, inputs, filter bar |
| `divider` | `#E7E7E7` | `#3F4756` | Table rows, sidebar section rules |
| `shadow-card` | `6px 6px 54px rgba(0,0,0,0.05)` | none | Cards |
| `shadow-pop` | `0 13px 61px rgba(169,169,169,0.37)` | `0 13px 61px rgba(0,0,0,0.45)` | Filter popovers |

The fixed colors are the same in both modes:

| Token | Hex | Used for |
|---|---|---|
| `brand` | `#4880FF` | Primary buttons, active link, bell, chart line |
| `success` | `#00B69B` | Completed-style labels, upward trend, positive delta |
| `danger` | `#EF3826` | Rejected-style labels, delete icon |

Labels (`Badge`) are 93 × 27, radius 4.5px, 12px bold. In light mode they use the tone at 20% behind tone-colored text. In dark mode they use the solid tone behind white text.

Stat tiles are 60 × 60, radius 23px. Light: tone at 21% behind a tone-colored icon. Dark: solid tone behind a white icon.

The theme toggle sits in the top bar. It writes `theme` to `localStorage`. An inline script in the root layout `<head>` adds `.dark` before the first paint.

## Layout and spacing
- Sidebar: 240px open, 84px closed. A 70px top cell holds the logo when open and the menu button when closed.
- Sidebar link: 50px tall. Open: 24px side margin, 192px wide, radius 6px, text inset 54px. Active link: `bg-brand text-white` plus a 4px blue bar on the left edge. Closed: centered 20px icon, blue when active, plus the same bar.
- Sidebar sections are separated by a full-width `divider` rule with 16px above and below. Labelled sections put the label at 40px from the left with 16px below it.
- Top bar: 70px tall, `bg-surface`, 30px side padding. Open sidebar: menu button, then a 388 × 38 rounded search pill. Closed sidebar: the search has no pill and the language picker is hidden. Right side: theme toggle, bell (24px, count badge), UK flag (40 × 27) with "English", a 44px avatar, name and role, and an 18px chevron circle.
- Content: 30px padding. Page header to first block: 28px. Gaps between cards: 30px.
- Card: `bg-surface`, radius 14px, `shadow-card`, 32px padding. In dark mode a `line` border replaces the shadow.
- Stat cards: 4 across (262 × 162 at 1440), 16px padding.
- Filter bar: 70px tall, radius 10px, `bg-head`, `line` border and separators. Cells: a 67px funnel cell, "Filter By", one cell per filter (24px padding, 26px to the chevron), then Reset Filter in `alert`. The table follows 24px below.
- Filter popover: 522px wide, radius 26px, `shadow-pop`. Title, then 34px pill chips in 3 columns. When more than one can be chosen, a divider and "*You can choose multiple …" follow, then a 129 × 36 Apply Now button.
- Table card: radius 14px, `line` border. Head row 48px on `bg-head`. Body rows 74px with `divider` rules. Cells use 32px side padding.
- Row actions: a 96 × 32 pair (edit, delete) with a `line` border, radius 8px. The delete icon is `danger`.
- Pagination: "Showing 1-09 of 78" on the left, and on the right a 86 × 31 pair of chevron buttons, radius 12px. It sits 20px below the table.
- Primary button: 48px tall, 24px padding, radius 8px, 14px bold.
- Form (modal or form card): two 360px columns with a 60px gap, centered in a 780px block. Label, then 12px, then a 52px input (`bg-field`, `line` border, radius 4px). Rows are 30px apart. Submit: 274 × 56, radius 12px, `bg-brand/90`, centered 46px below the fields.
- Modal: up to 900px wide, radius 14px, 60px side padding, 24px title and a 30px round close button.

## Shell
The sidebar follows the backend modules. The links are grouped the way the kit groups them: main links, then labelled sections, then Logout at the bottom.

| Section | Links | Backend guide |
|---|---|---|
| (main) | Dashboard, Products, Branches, Inventory, Movements | v0.2, v0.3, v0.4 |
| Access | Users, Roles, Audit | v0.5, v0.6, v0.7 |
| Integration | Scan, Import | v0.8 |
| (bottom) | Logout, which opens `/login` | |

The menu button toggles the sidebar between open (Style 1) and closed (Style 2). Search, bell, language, and avatar are visual only.

`/login` is outside the shell. Sign in opens the dashboard with no credentials and no token. `/` redirects to `/dashboard`.

## Screens
Each page keeps its own array in state. Create, edit, and delete change that array only. Forms open in a modal.

| Screen | Kit reference |
|---|---|
| Login | Light 1 `Dashboard # 26` (Login to Account) |
| Dashboard | Light 1 `Dashboard #1` (stat cards, Sales Details, Deals Details) |
| Products, Inventory, Movements, Audit | Light 1 `Dashboard # 9`–`# 15` (Order Lists with filter bar and popovers) and `# 16` (Product Stock row actions) |
| Branches | Light 1 `Dashboard # 25` (Table) plus a card like Sales Details for the map |
| Users | Light 1 `Dashboard # 24` (Team cards) with the Contact card's outline button |
| Roles | Light 1 `Dashboard # 5` (Inbox: left list, right checklist) |
| Scan, Import | Light 1 `Dashboard # 30` (Add New Contact form card) |
| All modals | Light 1 `Dashboard # 30` and `# 36` (form grid and Add Now button) |

- **Login.** A blue page with soft lighter blobs. A 630px white card (radius 24px, 57px side padding, 90px top and bottom). It holds the title, a subtitle, Username, Password, Remember Password, a 418 × 56 Sign In button, and a footer line.
- **Dashboard.** Four stat cards: Total Products, Branches, Movements Today, and Low Stock, each with a trend line. A Stock Movements line chart card with a month picker. A Latest Movements table on a `panel` head row, with a movement-type label.
- **Products.** Header: search pill (253 × 38, filters name or SKU) and Add New Product. Filter bar: Category (multiple choice), Sort By (`occurred_at` or `name`, default `occurred_at`), Direction (default `desc`), and Size. Size `All` means an empty `size`, which returns every row. `page` is required and is driven by the pagination buttons. Columns: SKU, name, category, unit, reorder level, actions. Create and edit fields: `sku`, `barcode`, `name`, `description`, `category`, `unit`, `reorder_level`. The delete action deactivates the product, which hides the row.
- **Branches.** Add New Branch. A table with code, name, address, an Active label, and an edit action. Below it, a Branch Map card: a grid placeholder with a blue pin and code label for each branch. Create and edit include latitude and longitude. No Leaflet package in the mock.
- **Inventory.** The filter bar has one Branch filter (single choice). Columns: SKU, name, unit, quantity, reorder level, status. Status is a `danger` "Low" label when quantity is at or below the reorder level, otherwise a `success` "In Stock" label.
- **Movements.** Header buttons Receipt, Issue, Adjustment, and Transfer each open a form. Transfer adds a To Branch field. The filter bar has a Type filter (multiple choice). Columns: time, type label, SKU, branch, delta (green or red), balance, source. Label tones: Receipt `success`, Issue `danger`, Adjustment `warning`, Transfer `magenta`.
- **Scan.** A form card with a round scan icon, then Barcode and Quantity fields. Below them, a result panel shows the product or a hint. When a product is found, Receipt (solid) and Issue (outline) buttons post a message.
- **Import.** A form card whose round icon is the file picker, a hardcoded dry-run table with a result label per row, and a Confirm button. The file is not parsed.
- **Users.** Add New User. Team-style cards, 4 across. Each card has a 110px initials avatar, full name, role, username, branch and active labels, and an outline Edit button. Create and edit. On edit the password field is New Password and can be left blank.
- **Roles.** A 286px left card lists the roles with granted counts and the permission groups as colored squares. The right card has a permission search and one row per permission code: checkbox, group label, and code. Super Admin is shown and cannot be edited.
- **Audit.** The filter bar has Action and Entity filters (multiple choice). Columns: time, actor, action label, entity, branch, details.

## Shared components
`src/components/` holds the pieces every screen reuses: `Shell`, `Logo`, `Icon` (inline SVG, no icon package), `ThemeToggle`, `InlineScript`, `PageHeader` and `PrimaryButton`, `Card` and `MonthPicker`, `Table`, `Row`, `Cell`, and `RowActions`, `Badge`, `FilterBar` and `FilterChoice`, `Pagination`, `Form` (`FormGrid`, `Field`, `SelectField`, `SubmitButton`, `PhotoCircle`), `Modal` and `ModalActions`, and `LineChart` (hand-drawn SVG, no chart package). `src/lib/format.ts` holds the UTC date formatting and the movement label tones.
