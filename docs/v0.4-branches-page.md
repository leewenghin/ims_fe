# Frontend v0.4: Branches Page

## Goal
Repeat the v0.3 pattern for branches, mostly from memory, and create a `BranchSelect` component that the inventory and movement pages need next.

## Prerequisites
Backend v0.3 and frontend v0.3 are done.

## Files

| Action | Path |
|---|---|
| Create | `src/types/branch.ts` |
| Create | `src/services/branchService.ts` |
| Create | `src/components/BranchForm.tsx`, `src/components/BranchSelect.tsx`, `src/components/FormSelect.tsx` |
| Change | `src/app/branches/page.tsx` |

## Steps

### 1. Types and service
- `Branch { id; code; name; address: string | null; active: boolean; createdAt; updatedAt }`
- `BranchRequest = { code; name; address }`
- `branchService`: `list(activeOnly?: boolean)` (returns `Branch[]`, not paged), `get`, `create`, `update`, `remove`.

### 2. `FormSelect`
This works like `FormInput` but wraps `<select>`. Props: `label`, `name`, `error?`, `options: { value: string | number; label: string }[]`, `placeholder?`, plus the native select props.

### 3. `BranchSelect`
- Props: `value: number | null`, `onChange(id: number | null)`, `allowAll?: boolean` (adds an "All branches" option), `disabled?`.
- It fetches internally with `useQuery({ queryKey: ["branches", "active"], queryFn: () => branchService.list(true) })`. Labels look like `"KL01 - KL City Store"`.
- Several components can use the same query key. TanStack Query only fetches once and shares the cache between them.

### 4. Branches page
- A table with columns Code, Name, Address, Status (Active/Inactive badge), and actions.
- Create and edit happen in a `Modal` with `BranchForm`. Uppercase the code as the user types.
- Deactivate asks for confirmation. Show a 409 from the backend ("branch still has stock", once v0.5 is done) as an alert.
- After any mutation, invalidate `["branches"]`. This also refreshes every `BranchSelect`.

## Done checklist
- [ ] The 3 seeded branches are listed
- [ ] Create, edit and deactivate work, and a duplicate code shows the 409 message
- [ ] `BranchSelect` renders the branches when you place it temporarily on the dashboard
- [ ] After creating a branch, it appears in `BranchSelect` without a reload
